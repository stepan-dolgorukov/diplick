# Шаблон ВКР

Файл-наставление для ИИ-агентов (и людей), которые правят этот репозиторий.
Здесь собраны: нормативные требования к оформлению ВКР, карта шаблона, готовые
рецепты и запреты. Если правило расходится с тем, что написано в этом файле,
приоритет имеет нормативный документ — Положение ИЕНиМ 2024 (его требования
перенесены сюда, см. § 1).

---

## 0. Кратко: что здесь есть и что делать

В репозитории **восемь файлов**:

- `thesis/thesis.tex` — **главный** файл шаблона ВКР. Собирается XeLaTeX +
  `latexmk`; результат — `thesis/thesis.pdf`.
- `report/report.tex` — самостоятельный бланк отзыва руководителя ВКР по форме
  инструкции ВКР 2026; результат — `report/report.pdf` (см. § 32).
- `AGENTS.md` — этот файл: требования, карта шаблона, рецепты и запреты.
- `compile.sh` — сборка PDF: `./compile.sh thesis/thesis.tex` (вне `nix develop` сам
  перезапускается через него).
- `flake.nix`, `flake.lock` — окружение сборки: TeX Live (XeLaTeX, `latexmk`,
  нужные пакеты), Times New Roman (`corefonts`), Liberation Mono, `poppler-utils`.
- `vkr_requirements_ienim_2024.pdf` — Положение ИЕНиМ УрФУ о ВКР (2024).
- `vkr_requirements_urfu_2022.pdf` — общеуниверситетский стандарт УрФУ (2022).

Нормативные документы в репозитории: их требования перенесены в § 1–24.
Сборка не требует никаких внешних файлов: титул, задание и все примеры
набраны прямо в `thesis/thesis.tex`.

**Главное правило:** ничего не «улучшать» по памяти. Любое изменение
оформления должно опираться на конкретное требование из § 1–24 (с указанием
страницы нормативного документа), а не на общие представления о ГОСТ.

> **Что проверяют чаще всего:** A4; поля 30/15/20/20 мм; Times New Roman 14 pt;
> интервал 1,5; абзац 1,25 см; выравнивание по ширине; переносы; номера
> страниц внизу по центру со 2-й; структурные заголовки — ПРОПИСНЫМИ,
> полужирным, по центру; разделы — с абзацного отступа; рисунки, таблицы и
> формулы — с нумерацией по разделу; список источников — без точки; каждое
> приложение — с новой страницы.

## 2. Сборка, проверка, артефакты

### 2.1. Команда сборки

Основной способ — скрипт, который сам поднимает окружение из `flake.nix`:

```bash
cd /home/sdd/programming/diplick
./compile.sh thesis/thesis.tex
./compile.sh report/report.tex
```

Внутри `nix develop` он работает напрямую, снаружи — один раз перезапускается
через `nix develop`, поэтому активировать оболочку вручную не обязательно.
PDF и рабочие файлы появляются рядом с `.tex`-файлом.

Если собирать `latexmk` вручную (в этом окружении `LD_LIBRARY_PATH` указывает
на Nix-библиотеки, из-за чего системный `xelatex` падает с
`GLIBC_2.38 not found`):

```bash
cd /home/sdd/programming/diplick
env -u LD_LIBRARY_PATH latexmk -xelatex -interaction=nonstopmode -halt-on-error thesis/thesis.tex
```

`latexmk` сам делает столько проходов, сколько нужно для содержания и ссылок.
Если собираете `xelatex` вручную — запускайте **минимум дважды**.

### 2.2. Обязательные проверки после правки

```bash
# 1. Код возврата должен быть 0
echo $?

# 2. Не должно быть переполнений и потерянных символов
grep -n "Overfull\|Missing character" thesis/thesis.log

# 3. Число страниц и формат
env -u LD_LIBRARY_PATH pdfinfo thesis/thesis.pdf | grep -E "Pages|Page size"

# 4. Текст и колонтитулы
env -u LD_LIBRARY_PATH pdftotext -layout thesis/thesis.pdf - | less

# 5. Визуальный контроль
env -u LD_LIBRARY_PATH pdftoppm -r 80 -png thesis/thesis.pdf /tmp/opencode/page
```

`Underfull \hbox` в коротком абзаце допустим (косметика), `Overfull \hbox` —
нет. `Missing character` — всегда ошибка (обычно шрифт не содержит глиф).

### 2.3. Артефакты

`*.aux`, `*.log`, `*.toc`, `*.out`, `*.xdv`, `*.fls`, `*.fdb_latexmk` —
рабочие файлы, их не редактируют руками и не считают результатом. Результат —
`*.pdf`.

Сборка создаёт `thesis/thesis.pdf` и рабочие файлы, но они в репозиторий не входят.
Перед рискованной правкой делайте копию файла в `/tmp/opencode/`.

### 2.4. Окружение Nix

`flake.nix` описывает `devShells.default` — единственное место, где перечислены
зависимости сборки:

| Что | Зачем |
|---|---|
| `texliveSmall.withPackages` | XeLaTeX, `latexmk` и пакеты шаблона: `fontspec`, `polyglossia`, `unicode-math`, `extsizes`, `caption`, `titlesec`, `ulem`, `booktabs`, `setspace`, `tex-gyre-math`, `collection-langcyrillic`, `collection-fontsrecommended` |
| `corefonts` | Times New Roman (метрики титула и бланка задания сверены именно с ним) |
| `liberation_ttf` | Liberation Mono для `\cyrillicfonttt` |
| `poppler-utils`, `qpdf` | проверки из § 2.2 и работа с PDF |
| `FONTCONFIG_FILE` (`makeFontsConf`) | fontspec ищет шрифты через fontconfig; без этого файла Times New Roman не находится |
| `shellHook` | снимает `LD_LIBRARY_PATH` (см. § 2.1) и выставляет `VKR_ENV=1` — по этой метке `compile.sh` понимает, что уже внутри оболочки |

`corefonts` помечен как unfree, поэтому в `flake.nix` стоит
`allowUnfreePredicate` ровно на этот пакет — не включайте `allowUnfree`
целиком. Версия nixpkgs зафиксирована в `flake.lock`; обновление —
`nix flake update`.

Проверка окружения:

```bash
nix develop --command bash -c 'xelatex --version; fc-match "Times New Roman"'
```

Ожидаемый вывод — TeX Live нужного года и `Times_New_Roman.ttf`. Если `xelatex`
падает с `GLIBC_2.38 not found`, значит сборка идёт вне оболочки с чужим
`LD_LIBRARY_PATH`: используйте `./compile.sh` или `env -u LD_LIBRARY_PATH`.

Артефакты другой версии TeX Live несовместимы: после смены окружения удалите
`*.aux`, `*.toc`, `*.out`, `*.xdv`, иначе polyglossia может упасть на старом
`thesis.aux`.

## 3. Обязательная структура ВКР

Порядок элементов жёсткий (ИЕНиМ, с. 9–11):

1. **Титульный лист** — по образцу, без номера страницы.
2. **Задание на выполнение ВКР** — сразу после титульного листа.
3. **Реферат**.
4. **Место выполнения работы**.
5. **Содержание**.
6. **Обозначения и сокращения**.
7. **Введение**.
8. **Основная часть**:
   1. Обзор литературы;
   2. Постановка задачи;
   3. Методика эксперимента (название может варьироваться, см. § 12);
   4. Результаты и их обсуждение.
9. **Заключение (Выводы)**.
10. **Список использованных источников и литературы**.
11. **Приложения** — при необходимости.

Дополнительно:

- после титульного листа обязательно идёт задание (ИЕНиМ, с. 12);
- в основном тексте должны быть ссылки и описание **всех** приложений;
- работа должна содержать все экспериментальные данные, использованные для
  получения результатов и выводов, — в графической или табличной форме
  (ИЕНиМ, с. 11);
- рекомендуемый объём ВКР бакалавра без приложений — **30–50 страниц**
  (ИЕНиМ, с. 4);
- обзор литературы — **не более 1/3** работы (ИЕНиМ, с. 12);
- оригинальность текста — **не менее 70 %** (ИЕНиМ, с. 7);
- на кафедру сдаётся PDF с отсканированным подписанным титульным листом
  (ИЕНиМ, с. 12).

## 4. Общие правила набора

| Параметр | Требование | Источник |
|---|---|---|
| Формат | A4, книжная ориентация, одна сторона листа | ИЕНиМ, с. 12 |
| Поля | левое 30 мм, правое 15 мм, верхнее 20 мм, нижнее 20 мм | ИЕНиМ, с. 12 |
| Гарнитура | Times New Roman | ИЕНиМ, с. 12 |
| Кегль основного текста | 12–14 pt; **в шаблоне ровно 14 pt** (строже и совпадает с УрФУ) | ИЕНиМ, с. 12; УрФУ, с. 15 |
| Межстрочный интервал | 1,5 | ИЕНиМ, с. 12 |
| Абзацный отступ | 1–1,25 см; **в шаблоне 1,25 см** | ИЕНиМ, с. 12 |
| Выравнивание | по ширине | ИЕНиМ, с. 12 |
| Переносы | обязательны | ИЕНиМ, с. 12 |
| Цвет | чёрный | ИЕНиМ, с. 12 |
| Язык | русский | ИЕНиМ, с. 12 |

Дополнительно:

- акцентирование допускается сменой начертания/гарнитуры, но не кегля
  (УрФУ, с. 16);
- курсив — для латинских терминов и названий объектов (`in vitro`), УрФУ, с. 16;
- работа брошюруется в неразъёмный блок; листы в файлы-вкладыши не помещают.

> **Ловушка extsizes.** Опция `14pt` у `extarticle` берёт классический
> `\@xivpt`, то есть **14,4 pt**, а не 14. Поэтому сразу после
> `\documentclass` стоит `\renewcommand\normalsize{\@setfontsize\normalsize{14}{17}}`
> (в `\makeatletter`-блоке). Без этой строки весь текст на 2,9 % крупнее
> требуемого, а строки — шире. Не удаляйте её и не «упрощайте» до
> `\fontsize{14}{17}\selectfont` без проверки: `\@setfontsize` ещё и
> выставляет `\@currsize`.

В шаблоне это задано через `geometry`, `setspace` (`\onehalfspacing`),
`\parindent=1.25cm`, `\tolerance=2000`, `\emergencystretch=3em`. **Не
уменьшайте кегль и не меняйте поля** без явного указания.

### 4.1. Язык и терминология

ИЕНиМ, с. 12–13:

- текст — на грамотном русском языке, в научно-техническом стиле, без
  жаргонизмов и подчёркнутой эмоциональной окраски;
- термины, обозначения и определения — общепринятые в соответствующей
  области;
- произвольные сокращения слов и замена слов знаками запрещены;
- сокращения — по ГОСТ ИСО 8601, ГОСТ 7.88, ГОСТ 7.11, ГОСТ 7.0.12;
- физические величины — по ГОСТ 8.417, как правило в СИ; внесистемные
  единицы — с указанием соотношения;
- чертежи и схемы — по ЕСКД, как правило на листах A1;
- изложение — настолько краткое, насколько это возможно без потери смысла.

## 5. Нумерация страниц

- Сквозная, арабскими цифрами, по всему тексту, включая приложения, **без
  пропусков и повторений**.
- Номер — внизу страницы **по центру**, без точки (ИЕНиМ, с. 12).
- Титульный лист входит в нумерацию, но номер на нём **не печатается**.
- Нумерация начинается со второго листа (задание — страница 2).
- Иллюстрации и таблицы на отдельных листах входят в общую нумерацию; лист
  A3 считается одной страницей.

В шаблоне: `\pagestyle{plain}` + переопределённые `\@oddfoot`/`\@evenfoot`
(`\hfil\thepage\hfil`), на титуле `\thispagestyle{empty}` и
`\setcounter{page}{2}` после него.

## 6. Заголовки

### 6.1. Структурные элементы

Заголовки обязательных элементов («РЕФЕРАТ», «СОДЕРЖАНИЕ», «ВВЕДЕНИЕ»,
«ЗАКЛЮЧЕНИЕ (ВЫВОДЫ)», «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ И ЛИТЕРАТУРЫ» и
т. п.):

- располагаются **в середине строки** (по центру), без абзацного отступа;
- **ПРОПИСНЫМИ** буквами;
- **полужирным**;
- без подчёркивания;
- **без нумерации**;
- **без точки** в конце;
- **без переносов слов**;
- каждый элемент начинается **с новой страницы**.

(ИЕНиМ, с. 13; УрФУ, с. 40.)

### 6.2. Разделы, подразделы, пункты

- Разделы нумеруются арабскими цифрами **без точки** после номера, заголовок
  печатается **с абзацного отступа**, с прописной буквы, полужирным, без
  точки в конце (ИЕНиМ, с. 13–14).
- Подразделы: номер `1.1`, `1.2`, … в пределах раздела; точка после номера не
  ставится.
- Пункты: `1.1.1`, `1.1.2`, …; подпункты: `1.1.1.1` и т. д.
- Если заголовок состоит из нескольких предложений, они разделяются точкой.
- Переносы в заголовках запрещены; нельзя переносить слово на союзе или
  предлоге (УрФУ, с. 40).
- Слово «глава» не используется — только номер и заголовок.

В шаблоне:

| Команда | Что делает |
|---|---|
| `\structheading{ТЕКСТ}` | центрированный заголовок без новой страницы и без TOC |
| `\structtitle{ТЕКСТ}` | новая страница + центрированный заголовок + запись в содержание |
| `\fronttitle{ТЕКСТ}` | новая страница + центрированный заголовок **без** записи в содержание |
| `\section{...}` | нумерованный раздел с абзацного отступа, новая страница — вручную `\clearpage` |
| `\subsection{...}` | подраздел `3.1` |
| `\subsubsection{...}` | пункт `3.1.1`, полужирный |

Записи в содержание: `\structtitle` для ОБОЗНАЧЕНИЙ, ВВЕДЕНИЯ, ЗАКЛЮЧЕНИЯ и
СПИСКА; `\fronttitle` для РЕФЕРАТА, МЕСТА ВЫПОЛНЕНИЯ и СОДЕРЖАНИЯ (последние
в содержание не включаются — это соответствует примеру УрФУ, с. 24).
ЗАДАНИЕ оформляется через `\structheading` и в содержание не попадает.

**Никогда не используйте `\section*`** — он ломает нумерацию, ссылки и
содержание.

## 7. Перечисления

- Перед элементом ставится маркер списка: **тире (–)** либо дефис.
  ИЕНиМ (с. 14) называет маркер «дефисом», УрФУ (с. 46) требует именно тире
  и прямо запрещает дефис. Типографски верное решение — тире; расхождение
  зафиксировано в § 24.
- Для ссылок в тексте — строчная буква кириллицы со скобкой: `а)`, `б)`, `в)`;
  запрещены `ё, з, й, о, ч, ъ, ы, ь`.
- Для дальнейшей детализации — арабские цифры со скобкой: `1)`, `2)`.
- Перечисления идут с абзацного отступа, в столбик.
- Простые перечисления разделяются запятой, сложные — точкой с запятой.
- Прописные/строчные в начале пункта и завершающий знак — по правилам
  русского языка.

Пример вложенности (ИЕНиМ, с. 14):

```text
а) _____
б) _____
   1) _____
   2) _____
в) _____
```

В шаблоне готового окружения для перечислений нет — используйте `itemize` с
настройкой маркера или обычные абзацы с тире. Если добавляете пакет
(`enumitem`), проверьте сборку и не меняйте отступы глобально.

## 8. Реферат

Реферат — с. 9 ИЕНиМ, с. 21–23 УрФУ.

Состав (строго в этом порядке):

1. **Сведения об объёме** — с абзацного отступа, в строку, через запятые:
   `Отчет __ с., __ рис., __ табл., __ источн., __ прил.`
   Формы слов согласуются с числами.
2. **Ключевые слова** — от 5 до 15 слов или словосочетаний:
   - в именительном падеже;
   - **ПРОПИСНЫМИ** буквами;
   - в строку, через запятые;
   - **без абзацного отступа**;
   - **без переноса слов**;
   - **без точки** в конце перечня.
3. **Текст реферата** — с абзацного отступа, после ключевых слов. Отражает:
   - объект исследования;
   - цель работы;
   - методы/методологию;
   - результаты и их новизну;
   - область применения;
   - значимость работы (рекомендации по внедрению, экономическая
     эффективность, прогноз — при наличии).

Объём текста реферата — оптимально **850 печатных знаков**, но **не более
одной страницы**. Отсутствующие части опускаются с сохранением
последовательности.

Для бакалавра реферат — на русском языке; для специалиста и магистра — на
русском **и английском**.

В шаблоне реферат — это бланк:

```latex
\fronttitle{РЕФЕРАТ}
Отчет \underline{\hspace{1.2cm}} с., \underline{\hspace{0.8cm}} рис., ...
\refkeywords{Ключевые слова:}
\refblankline{Объект исследования~— }
...
```

`\refblankline{...}` и `\refkeywords{...}` печатают текст и подчёркивание,
рассчитанное до правого поля. **Заполняя реферат, заменяйте эти вызовы
обычными абзацами** — не вписывайте длинный текст в аргумент, иначе
подчёркивание уедет за поле.

## 9. Содержание

- Включает наименования **всех разделов, подразделов и пунктов** с номерами
  страниц (ИЕНиМ, с. 10).
- Каждая запись — отдельный абзац, выровненный влево.
- После наименования — **отточие**, номер страницы — у правого края.
- Подразделы — с отступом ~2 знака относительно разделов, пункты — ~4 знака
  (УрФУ, с. 25).
- Содержание собирается автоматически; после правки заголовков пересоберите
  документ (лучше дважды).

В шаблоне отступы уровней заданы классом `article` (`1.5em` и `3.8em`). Если
нормоконтролер требует строго 2 и 4 знака, их уменьшают через
`\l@subsection`/`\l@subsubsection` — но это меняет вид всего содержания,
поэтому делайте так только по замечанию.

В шаблоне: `tocdepth=3`, `\l@section` переопределён на `\@dottedtocline`,
поэтому отточие есть у всех уровней. Заголовки структурных элементов
добавляются в TOC только через `\structtitle`.

## 14. Рисунки

Источник: ИЕНиМ, с. 14–15; УрФУ, с. 48–50.

### 14.1. Размещение

- Непосредственно после текста, где рисунок упоминается впервые, или на
  следующих страницах.
- Допускается несколько рисунков на одном листе.
- Рисунки выполняются компьютерным способом; графики — с системой координат,
  разметкой и единицами измерения на осях.
- Фотографии — сканирование **не ниже 300 dpi**, при необходимости
  гамма-коррекция; цветная печать — только если цвет важен для понимания.
- Большие рисунки, не помещающиеся на A4, — в приложения.
- На **все** рисунки должны быть ссылки в тексте.

### 14.2. Подпись

- Под рисунком, **по центру строки** для однострочной подписи и **по ширине**
  для многострочной.
- Формат: `Рисунок 2.1 – Название` (номер, тире, название). В образце ИЕНиМ
  и в шаблоне используется короткое тире «–» (U+2013).
- Нумерация — **по разделу**: номер раздела, точка, номер рисунка в разделе.
  Точка после номера не ставится.
- В конце подписи точка **не ставится**.
- Переносы слов в наименовании рисунка не допускаются.
- Подпись должна быть понятна вне текста работы; кривые и символы на поле
  рисунка нумеруют цифрами, расшифровка — в подписи (экспликация).
- Рисунки приложений: `Рисунок А.3`.

### 14.3. Ссылки

- «… в соответствии с рисунком 1.2»;
- «(см. рисунок 1.2)».

### 14.4. Шаблон

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{fig/spectrum.pdf}
  \caption{Спектры поглощения системы ПЭО–хитозан}
  \label{fig:spectrum}
\end{figure}

На рисунке~\ref{fig:spectrum} приведены спектры поглощения.
```

Подпись настраивается глобально: `\small` (12 pt), `labelsep=endash`,
выравнивание по центру/по ширине. **Не переопределяйте `\caption` вручную** —
используйте `\captionsetup`, если нужен особый случай.

После рисунка обязательно должен идти анализ/вывод (не менее абзаца): текст
не должен заканчиваться рисунком (УрФУ, с. 56).

## 15. Таблицы

Источник: ИЕНиМ, с. 15–16; УрФУ, с. 51–56.

### 15.1. Название и размещение

- Название — **над таблицей, слева, без абзацного отступа**, в одну строку с
  номером, отделено **тире**.
- Формат: `Таблица 3.1 – Название`.
- Точка в конце названия не ставится; точка после номера не ставится.
- Нумерация — по разделу (как у рисунков). Таблицы приложений — `Таблица А.1`.
- Таблица размещается после первого упоминания или на следующей странице.
- Ссылка в тексте — до таблицы, словом «таблица» с номером.

### 15.2. Структура

- Заголовок таблицы отделяется горизонтальными линиями; обязательна
  **закрывающая горизонтальная линия**.
- Вертикальные линии-разделители — по усмотрению автора (допустимы, но не
  обязательны).
- Строки и столбцы должны иметь заголовки; для физических величин в заголовке
  указывается единица измерения.
- Заголовки граф — с прописной, подзаголовки — со строчной, если составляют
  одно предложение с заголовком; точки в конце не ставятся; единственное
  число.
- Диагональные линии не допускаются.
- Повторяющийся текст: первое повторение — «то же», далее — кавычки; цифры и
  обозначения кавычками не заменяют.
- Кегль таблицы: ИЕНиМ отдельно не оговаривает — применяется основной
  (12–14 pt); УрФУ требует не менее 12 pt при основном 14 pt (с. 52).
- Перенос: слово «Таблица» и номер — один раз над первой частью, над
  продолжением — «Продолжение таблицы 3.1»; заголовок повторяют над каждой
  частью. Одна строка таблицы на странице не оставляется.
- Оформление таблиц — по ГОСТ 2.105 и ГОСТ 7.32 (ИЕНиМ, с. 16).

### 15.3. Шаблон

```latex
\begin{table}[htbp]
  \caption{Влияние концентрации на вязкость раствора}
  \label{tab:viscosity}
  \begin{tabular}{@{}lcc@{}}
    \toprule
    Концентрация, % & $\eta$, мПа$\cdot$с & $T$, K \\
    \midrule
    0,5 & 1,12 & 298 \\
    1,0 & 1,34 & 298 \\
    \bottomrule
  \end{tabular}
\end{table}

В таблице~\ref{tab:viscosity} приведены результаты измерений.
```

`booktabs` даёт горизонтальные линейки без вертикальных — это допустимо.
Если нужны вертикальные линии, используйте `tabular` с `|`, но не смешивайте
стили в одной работе.

После таблицы — анализ данных (не менее абзаца).

## 16. Формулы и химические структуры

Источник: ИЕНиМ, с. 16–17; УрФУ, с. 60–61.

### 16.1. Оформление

- Выключные формулы — **отдельной строкой**, **по центру**.
- Нумеруются все выключные формулы; номер — в круглых скобках, **у правого
  края**, по разделу: `(4.1)`.
- Выше и ниже формулы — **не менее одной свободной строки**.
- В конце формулы — знак препинания в контексте предложения.
- Пояснение («где …») — сразу под формулой, в той же последовательности, что и
  в формуле (ИЕНиМ, с. 16); УрФУ дополнительно требует каждый символ с новой
  строки (с. 61):
  - начинается со слова «где» **без двоеточия**, с абзаца;
  - после символа — тире, расшифровка, точка с запятой; последняя — точка.
- Перенос длинной формулы — после `=`, `+`, `−`, `×`, `:` и других знаков;
  знак повторяется в начале следующей строки. При переносе на умножении —
  только знак `×`.
- Ссылки: «в формуле (1)», «в формуле (2.1)», «в формулах (3)–(5)».
- Формулы приложений: `(В.1)`.

### 16.2. Химические структуры

Для структурных формул химических соединений (ИЕНиМ, с. 17):

- используются специализированные редакторы (ChemDraw, ChemWin и др.);
- формула помещается в отдельную строку;
- нумеруется **римскими цифрами**;
- нумерация **сквозная по всему тексту** (не по разделам).

Это единственное исключение из правила «нумерация по разделу» — не
переводите структурные формулы на арабские цифры.

### 16.3. Шаблон

```latex
Уравнение состояния идеального газа имеет вид
\begin{equation}
  pV = nRT,
  \label{eq:state}
\end{equation}
где $p$~— давление;\\
$V$~— объём;\\
$n$~— количество вещества;\\
$R$~— универсальная газовая постоянная;\\
$T$~— температура.

Формула~\eqref{eq:state} приведена в качестве примера.
```

Если нормоконтролер допускает пояснение в строку, `\\` можно убрать: ИЕНиМ
требует только ту же последовательность символов, а не разбивку по строкам.

В шаблоне подключён `amsmath`, `\counterwithin{equation}{section}`, а
`\abovedisplayskip`/`\belowdisplayskip` приравнены к `\baselineskip`, чтобы
выполнялось требование о свободной строке. Математический шрифт — Times New
Roman (через `unicode-math` + `TeX Gyre Termes Math`), гарнитура формул не
отличается от текстовой.

## 17. Единицы физических величин и числа

Источник: ИЕНиМ, с. 17.

- Допускается либо международное (латиница/греческий), либо русское
  обозначение единиц; **смешивать нельзя**.
- Буквенные обозначения единиц — прямым шрифтом.
- Точку как знак сокращения в обозначении единицы **не ставят**.
- Обозначение ставится за числом, в строку, без переноса.
- Между числом и единицей — **пробел**.
- Дробь с косой чертой перед единицей — в скобках.

| Правильно | Неправильно |
|---|---|
| `100 кВт` | `100кВт` |
| `80 %` | `80%` |
| `20 °C` | `20°C` |
| `(1/60) s` | `1/60/s` |

В LaTeX неразрывный пробел: `100~кВт`, `80~\%`, `20~°C`.

## 18. Ссылки и список источников

Источник: ИЕНиМ, с. 17–20; УрФУ, с. 35, 67–72.

### 18.1. Ссылки в тексте

Допустимы три варианта:

1. Арабские цифры в квадратных скобках сразу за упоминанием: `[20]`.
   Несколько источников: `[2, 5, 9–12]`.
2. Знак выноски надстрочным индексом: `… 59`.
3. Без нумерации: `[Бахтин, 2003, с. 18]`.

Нумерация — **сквозная по всему тексту**. Один источник указывается в списке
**один раз**; при повторном цитировании используется тот же номер.

Косвенное цитирование допускается, доля — **не более 20 %**, оформляется:
`… – Цит. по [6]`.

### 18.2. Список источников

- Источники располагаются **в порядке появления ссылок** в тексте
  (для биологии и экологии — по алфавиту).
- Нумеруются арабскими цифрами **без точки** и печатаются **с абзацного
  отступа** (ИЕНиМ, с. 18).
- Оформление — по ГОСТ 7.1, ГОСТ Р 7.0.5, ГОСТ 7.80, ГОСТ 7.82 (электронные).
- После точки в инициалах обязателен пробел: `А. А. Тагер`, а не `А.А.Тагер`.
- Заголовок раздела: «СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ И ЛИТЕРАТУРЫ».

> В УрФУ (с. 35) номер печатается **с точкой**. Это расхождение; в шаблоне
> реализован вариант ИЕНиМ — без точки.

### 18.3. Примеры записей (ИЕНиМ, с. 18–20)

В библиографических записях ИЕНиМ использует **короткое тире «–»**, а не
длинное «—»; в основном тексте работы — наоборот, длинное «—». Не путайте.

## 19. Приложения

Источник: ИЕНиМ, с. 11; УрФУ, с. 36–37.

- Каждое приложение — **с новой страницы**.
- Сверху по центру: `ПРИЛОЖЕНИЕ А`, ниже — статус: `(обязательное)` или
  `(справочное)`, ниже — **название ПРОПИСНЫМИ** отдельной строкой по центру,
  без точки.
- Обязательное приложение содержит сведения, необходимые для понимания
  исследования; справочное — промежуточные результаты и примеры.
- Обозначение — прописные буквы кириллицы начиная с А, **кроме** `Ё, З, Й, О,
  Ч, Ъ, Ы, Ь`. Если алфавит исчерпан — допускаются арабские цифры.
- Одно приложение — `ПРИЛОЖЕНИЕ А`.
- Формат — A4 (допускается A3).
- Нумерация внутри: разделы `А.1`, рисунки `А.3`, таблицы `А.1`, формулы
  `(В.1)`.
- Сквозная нумерация страниц сохраняется.
- На все приложения — ссылки в тексте.
- Все приложения перечисляются в содержании с наименованием и статусом.

Шаблон:

```latex
\clearpage
\phantomsection
\addcontentsline{toc}{section}{ПРИЛОЖЕНИЕ А (обязательное). ДОПОЛНИТЕЛЬНЫЕ МАТЕРИАЛЫ}
\begingroup
  \centering
  \parindent=0pt
  \hyphenpenalty=10000\exhyphenpenalty=10000
  \textbf{ПРИЛОЖЕНИЕ А}\par
  (обязательное)\par
  \textbf{ДОПОЛНИТЕЛЬНЫЕ МАТЕРИАЛЫ}\par
\endgroup
\vspace{0.5\baselineskip}
```

Для приложения Б скопируйте блок и замените букву; для рисунков приложения:

```latex
\renewcommand{\thefigure}{Б.\arabic{figure}}
\setcounter{figure}{0}
```

### 20.2. Как устроен титул в шаблоне

Титул **векторный** и набран прямо в `thesis/thesis.tex` (блок
«ТИТУЛЬНЫЙ ЛИСТ»). Внешние файлы не нужны. Особенности:

- титул набирается **одинарным** интервалом с `\setstretch{0.95}` (шаг строк
  ≈16,1 pt, как в бланке); основной текст остаётся с интервалом 1,5;
- **поля титула отличаются от основных**: `\newgeometry{left=23.7mm,
  right=23.7mm,top=20mm,bottom=20mm}`, потому что бланк титула (и образец
  ИЕНиМ, с. 24) центрирован по физической странице, а не по блоку
  30/15 мм. Сразу после титула `\restoregeometry` возвращает 30/15/20/20 мм
  для всего остального документа. **Не удаляйте `\restoregeometry`** — без
  него вся работа печатается с полями 23,7 мм;
- гарнитура — Times New Roman, кегль — ровно 14 pt (см. § 4);
- все реквизиты выводятся из макросов (`\VKRTitle`, `\VKRStudentGenitiveTitle`,
  `\VKRDepartment`, `\VKRHeadPosition`, `\VKRHeadDegree`, `\VKRHeadName`,
  `\VKRNormControlDegree`, `\VKRNormControlName`, `\VKRAdvisorDegree`,
  `\VKRAdvisorInitials`, `\VKRAdvisorSurname`, `\VKRWorkType`, `\VKRPlace`,
  `\VKRYear`);
- `\VKRStudentGenitiveTitle` содержит `\\` — на титуле «Смирнова Юрия» и
  «Викторовича» стоят двумя строками, как в образце; `\VKRAdvisorInitials` и
  `\VKRAdvisorSurname` позволяют разорвать «И. С. Иванов» так же, как в
  образце (фамилия отдельной строкой);
- блок министерства: строки «федеральное…», «высшего образования» и
  «УРАЛЬСКИЙ…» смещены вправо на ~15 pt через
  `\makebox[\linewidth][c]{\hspace*{30pt}…}` — так в образце ИЕНиМ, с. 24;
- подписи — две колонки `0.44\textwidth` и `0.487\textwidth`, разделённые
  `\hfill`; блок нормоконтроля смещён на 5 pt вправо (`\hspace*{10pt}`);
- линии для подписей — **отдельные абзацы** с `\rule`, а не часть колонок:
  `\hspace*{-21.67pt}\rule{247.3pt}\hfill\rule{207.5pt}\hspace*{8.2pt}`
  (пара линий) и `\hspace*{246.93pt}\rule{207.5pt}` (линия соруководителя).
  Размеры даны в TeX pt: в PDF 1 pt = 72/72,27 bp, поэтому 247,3 pt ≈ 246,4 bp;
- город и год прижаты к низу через `\vfill`, ниже — `\vspace*{24.5pt}`:
  этот зазор воспроизводит нижний отступ бланка (в образце год стоит на
  ~24,5 pt выше нижней границы полосы).

Если на кафедре принят департамент, замените `\VKRDepartment` на название
департамента, а `\VKRHeadPosition` — на «Директор департамента». Если есть
научный соруководитель, добавьте третью строку с подписью в блок подписей.

### 20.3. Ограничения

- Титул занимает **ровно одну страницу**. При удлинении темы, добавлении
  соруководителя или образовательной программы проверьте, что блок города и
  года не уехал на вторую страницу (`pdfinfo` покажет лишнюю страницу).
  Признак переполнения — «2026» в начале следующей страницы.
- Переносы на титуле отключены (`\hyphenpenalty=10000`), поэтому слишком
  длинная тема может дать `Overfull \hbox` — сократите тему или уменьшите
  вертикальные отступы, но не кегль.
- Грифы «СОГЛАСОВАНО»/«УТВЕРЖДАЮ» не печатаются: в образце ИЕНиМ их нет.
- Вертикальные отступы титула подобраны под образец с точностью ≤0,4 pt
  (базовые линии сверяются по координатам из PDF, а не «на глаз»).
  Если меняете содержимое блоков, пересоберите и проверьте, что город и год
  не сместились: они держатся на `\vfill` + `\vspace*{24.5pt}`.
- Поля титула (23,7 мм) — не ошибка: так центрирован бланк. Для остального
  документа действуют 30/15/20/20 мм (см. § 24).

### 21.1. Как устроен бланк в шаблоне

Бланк воспроизводит форму инструкции ВКР 2026 (`3_Задание_ВКР.pdf`): поля
**20/20/20/20 мм**, кегль 14 pt, шаг строк ≈16,1 pt, шапка повторяет титул
(министерство + институт). Сразу после бланка `\restoregeometry` возвращает
основные поля 30/15/20/20 мм — **не удаляйте его**.

| Средство | Назначение |
|---|---|
| `\newgeometry{left=20mm,right=20mm,top=20mm,bottom=20mm}` | поля бланка на одну страницу |
| `\vkrblank{ширина}` | линия поля толщиной 0,4 pt с нижним краем на 4 pt ниже базовой линии |
| `\underline{текст}` | заполненное поле с линией на той же высоте, что у `\vkrblank` |
| `\vkrdatefield{ширина}{значение}` | поле даты заданной ширины. Заполняйте второй аргумент, оставляя ширину из шаблона |
| `\vkrsigncaption` | надпись «(Подпись)» по центру соответствующей линии |
| `\vkrsmallstrut` | распорка для строк 10 pt: `\strut` сохраняет размеры 14 pt и ломает шаг |
| `minipage` 258,6 pt в `\raisebox{0pt}[0pt][0pt]` | блок «УТВЕРЖДАЮ» выровнен вправо с выходом на 16 pt за поле и не влияет на вертикальную арифметику |
| `\raggedright` (локально) | только для строки темы: иначе TeX растягивает пробелы, потому что длинное слово темы не переносится |

Вертикальные позиции базовых линий сверены с бланком (расхождение ≤0,5 pt),
поэтому отступы заданы дробными `\vspace*{…}`. При любой правке содержимого
бланка пересоберите документ и сверьте базовые линии по content-потоку PDF
(`Td`/`cm`), а не по bbox: у LibreOffice и XeTeX разные метрики bbox.
Тема берётся из `\VKRTitle`. Команда `\uline` из пакета `ulem` подчёркивает
текст темы с автоматическим переносом по строкам.

### 25.2. Структурные команды

| Команда | Новая страница | В содержание |
|---|---|---|
| `\structheading{...}` | нет | нет |
| `\structtitle{...}` | да | да |
| `\fronttitle{...}` | да | нет |
| `\section{...}` | вручную (`\clearpage`) | да |
| `\subsection{...}` | нет | да |
| `\subsubsection{...}` | нет | да |

### 25.3. Оформление

- `\counterwithin{figure}{section}`, `\counterwithin{table}{section}`,
  `\counterwithin{equation}{section}` — нумерация по разделу.
- `\captionsetup{font=vkrcaption,...}` — подписи 12 pt, `labelsep=endash`.
- `\captionsetup[table]{justification=raggedright,...}` — название таблицы
  слева без отступа.
- `sourcelist` — список источников без точки, с абзацным отступом.
- `\refkeywords`, `\refblankline` — строки реферата с подчёркиванием до
  правого поля.
- `\AtBeginDocument` задаёт `\abovedisplayskip` и `\belowdisplayskip`.
- Названия элементов (`\contentsname`, `\refname`, `\figurename`,
  `\tablename`) переопределены **после `\begin{document}`**, потому что
  polyglossia перезаписывает их при выборе языка. Если перенести эти
  `\renewcommand` в преамбулу — вернутся английские/стандартные названия.

### 25.4. Почему так, а не иначе

- `\tolerance=2000` + `\emergencystretch=3em` вместо `\sloppy`: сохраняет
  нормальные пробелы, но убирает переполнения.
- Заголовки центрируются вручную (`\centering`, `\parindent=0pt`), а не через
  `\section*`, чтобы не терять нумерацию и TOC.
- Отточие в TOC — переопределение `\l@section`, потому что стандартный
  `\l@section` для верхнего уровня отточие не печатает.
- Титул набирается вручную, без внешнего бланка: так он остаётся векторным,
  редактируется макросами и не зависит от картинок.
- Титул использует `\singlespacing`: при интервале 1,5 блок подписей и город
  не помещаются на одну страницу, а образец ИЕНиМ набран плотно.

## 26. Рецепты

### 26.1. Добавить раздел

```latex
\clearpage\section{Название раздела}
Текст.
```

Не ставьте точку после номера и в конце заголовка. Не используйте `\section*`.

### 26.2. Добавить подраздел/пункт

```latex
\subsection{Название подраздела}
\subsubsection{Название пункта}
```

### 26.3. Добавить рисунок

См. § 14.4. Файл изображения кладите в `fig/` (создайте при необходимости) и
используйте векторные форматы (PDF) для графиков.

### 26.4. Добавить таблицу

См. § 15.3. Для длинных таблиц подключайте `longtable` и проверяйте, что
заголовок повторяется, а над продолжением стоит «Продолжение таблицы N».

### 26.5. Добавить формулу

См. § 16.3. Для многострочных — `align`/`split` из `amsmath`; номер — у
правого края.

### 26.6. Добавить источник

Добавьте `\item ...` в `sourcelist` в порядке первого цитирования. Номер
ставится автоматически, точка не печатается.

### 26.7. Добавить приложение

Скопируйте блок из § 19, замените букву и название, добавьте
`\addcontentsline`. Не забудьте ссылку в тексте.

### 26.8. Добавить сокращение

Добавьте строку в таблицу раздела «ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ»:

```latex
ВКР & — выпускная квалификационная работа\\
```

Алфавитный порядок, без точки в конце строки.

### 26.9. Заполнить реферат

Замените `\refkeywords{...}` и `\refblankline{...}` обычными абзацами:

```latex
\fronttitle{РЕФЕРАТ}
Отчет 45 с., 12 рис., 5 табл., 30 источн., 2 прил.

\noindent Ключевые слова: ПОЛИЭТИЛЕНОКСИД, ХИТОЗАН, ХРОМАТОГРАФИЯ, ...

\noindent Объект исследования~— система полиэтиленоксид–хитозан.
...
```

## 29. Типовые ошибки

| Ошибка | Как правильно |
|---|---|
| `Рис. 4.1` | `Рисунок 4.1 – ...` |
| `Таблица 4.1. Название` | `Таблица 4.1 – Название` |
| Точка в конце подписи рисунка/таблицы | Без точки |
| Номер источника `1.` | `1` (ИЕНиМ) |
| Сквозная нумерация рисунков `1, 2, 3` | `4.1, 4.2` по разделу |
| Формула без номера | Все выключные формулы нумеруются |
| «где: p — …» | «где p — …» (без двоеточия) |
| Заголовок раздела по центру | Раздел — с абзацного отступа; по центру только структурные элементы |
| Заголовок с точкой | Без точки |
| Перенос в заголовке | Запрещён |
| `80%`, `20°C` | `80~\%`, `20~°C` |
| Смешение `кВт` и `kW` | Только одна система обозначений |
| Таблица 10 pt | Не меньше 12 pt |
| Текст заканчивается рисунком/таблицей | Добавить абзац анализа |
| Приложение без ссылки в тексте | Ссылка обязательна |
| Приложение без статуса | `(обязательное)` или `(справочное)` |

## 30. Ограничения и известные проблемы

- **В репозитории** находятся `thesis/thesis.tex`, `report/report.tex`, `AGENTS.md`,
  `compile.sh`, `flake.nix`, `flake.lock` и два PDF с нормативами
  (требования/положения ВКР).
  Рабочие файлы сборки и черновики не хранятся. Не добавляйте бланки, картинки
  и PDF в репозиторий без явной необходимости.
- **`LD_LIBRARY_PATH`.** Вне оболочки `nix develop` XeLaTeX падает без
  `env -u LD_LIBRARY_PATH`; `compile.sh` и `flake.nix` снимают эту проблему
  сами (§ 2.1, § 2.4).
- **Содержание обновляется не с первого прохода.** После правки заголовков
  запускайте `latexmk` повторно (обычно он делает это сам).
- **Шрифты.** Если `Times New Roman` не найден, XeLaTeX подставит другой
  шрифт и метрики поедут; проверяйте `fc-match "Times New Roman"`.
- **Титул — одна страница.** Следите, чтобы при длинной теме и большом числе
  подписантов город и год не уехали на вторую страницу.
- **Подписанный скан.** Итоговый PDF должен содержать скан титула с подписями;
  шаблон даёт только электронную верстку.

## 32. Бланк отзыва руководителя ВКР (`report/report.tex`)

Самостоятельный документ (не фрагмент `thesis/thesis.tex`), собранный по шаблону
`2б_Отзыв_ВКР_Руковд(УрФУ)+Соруковд(УрФУ).doc` (инструкция ВКР 2026).
Сборка: `./compile.sh report/report.tex`. Результат — ровно одна страница A4.

### 32.1. Метрики (сняты с PDF-эталона)

| Параметр | Значение |
|---|---|
| Формат | A4, книжная |
| Поля | 25,4 / 11,05 / 19 / 9,5 мм |
| Гарнитура | Times New Roman, 12 pt |
| Шаг строк | 13,8 pt (одинарный интервал Word) |
| Интервал «1,5» | 20,7 pt |
| Первая базовая линия | 65,2 pt от верха |
| Нумерация страниц | отсутствует (бланк не нумеруется) |

### 32.2. Как устроено

- **bp vs TeX pt.** Эталон набран в Word: его координаты — в bp (1/72").
  TeX-пункты меньше на 0,375 % (1 pt = 1/72,27"). Макрос `\vkrbp{#1}`
  переводит bp в pt: `\dimexpr#1pt*803/800\relax`. Все вертикальные
  расстояния и длины полей заданы в bp и прогоняются через `\vkrbp`.
- **`\vkrgap{d}`** — расстояние между базовыми линиями: `\par`,
  вычитает глубину предыдущей строки (`\vkrskip`) и снимает межстрочный
  клей (`\prevdepth=-1000pt`), чтобы результат равнялся `d` точно.
- **`\vkrgapabs{d}`** — то же, но от низа предыдущего бокса (таблицы):
  игнорирует глубину таблицы, чтобы следующая строка стояла на `d` ниже
  нижней линейки таблицы.
- **`\vkrp{...}`** — абзац с распоркой `\strut` (высота 9,696 pt).
- **Таблица** строится в `\sbox{\vkrtable}{...}` и выводится через
  `\usebox`, чтобы её высота учитывалась целиком; `\extrarowheight=0,25 pt`
  и распорка `\vkrstrut` (11,2 / 2,85 pt) дают высоты строк 55,7 / 28,1 pt
  как в эталоне. Строка `\\[-1.505pt]` перед `\hline` снимает
  пустое место под «хвостом» буквы «ц».
- **Ragged Right** абзац «Оценка соответствия ...» обёрнут в
  `\begingroup\raggedright ... \endgroup`, чтобы `raggedright` не утекал в
  следующие абзацы (и не отключал выравнивание по ширине в «Заключении»).
- **Запрет переноса** в фразе «достойным/недостойным» и в подсказке
  «направления «название направления»» — через `\mbox`, чтобы строки
  пустого бланка совпадали с формой. Заполненные код и название
  направления тоже собираются в `\mbox`.
- **`\vkrfield{ширина}{текст}`** — поле в bp. Пустой текст даёт `\vkrblank`.
  Короткий текст ложится на линию заданной ширины, она длиннее текста.
  Если текст шире поля, линия на 18 bp длиннее текста.
- **`\vkrvalueline{метка}{значение}`** — строка направления, программы,
  руководителя и соруководителя. Линия начинается у значения и идёт до
  правого края поля (486 bp), поэтому длиннее текста. Пустое значение
  команду не вызывает.
- **`\vkrtextbox{шаг}{строк}{метка}{текст}`** — многострочное поле. Шаг и
  число строк те же, что у пустого блока. На строке с меткой линия идёт
  от значения до правого края, на следующих — во всю ширину поля. Текст
  обрывается на 18 bp раньше линии, поэтому линия длиннее текста на каждой
  строке. Строки выводятся по одной через `\vkrgap`: пока текст умещается
  в отведённые строки, подпись и заключение не смещаются.

### 32.3. Заполнение

Данные отзыва задаются макросами перед `\begin{document}`. В файле
сейчас пример: студент, код и название направления, программа и
руководитель взяты из `thesis/thesis.tex`. Тема та же, обычным написанием:
в ВКР она хранится прописными для титула. Пустое значение `{}` оставляет
линию или подсказку бланка и возвращает соответствующее поле формы.

| Макрос | Поле |
|---|---|
| `\VKRTitle` | тема (2 строки) |
| `\VKRStudent` | Ф. И. О. студента; то же имя в заключении |
| `\VKRGruppa` | номер группы |
| `\VKRDirectionCode` | код направления |
| `\VKRDirection` | наименование направления, без кавычек: бланк ставит «» |
| `\VKRProgram` | образовательная программа |
| `\VKRAdvisor` | руководитель: Ф. И. О., степень, звание (должность) |
| `\VKRSorukovoditel` | соруководитель в том же формате |
| `\VKRMerits` | отмеченные достоинства (до 4 строк) |
| `\VKRShortcomings` | отмеченные недостатки (до 3 строк) |
| `\VKRGEKInfo` | дополнительная информация для ГЭК (до 3 строк) |
| `\VKRQualification` | квалификация в заключении; пусто — слово «бакалавр» из бланка |

Заполненные направление, образовательная программа, руководитель и
соруководитель печатаются на линии той же толщины, что Ф. И. О. и группа.
Подсказка «Ф.И.О., ученая степень…» у пустых руководителя и соруководителя
не подчёркивается.

Если текст темы, достоинств, недостатков или информации для ГЭК длиннее
отведённых строк, в логе появляется предупреждение `vkrreport`, и бланк
может выйти на вторую страницу. Если соруководителя нет — удалите строку
«Соруководитель» и блок с его подписью. Даты подписей по-прежнему
пустые линии.
